# 第二批 10 张标题模板 · 达芬奇试用清单

都是标题字卡。包在 5090 的 `D:\ograf-test\batch2\`，测试工程 `OGrafTest_261109` 里已经建好时间线，名字是 `B2_` 加卡名，打开就能看。

每张都先看这三样：播一遍动作对不对；检查器里改一处字、一处颜色，画面跟不跟着变；好不好看。下面只写每张特有的。

| 模板 | 默认画面 | 特别试一下 |
|---|---|---|
| 逐词浮现标题（blur-slide，4 秒） | 纸面上「把每一次发布，/ 拍成电影。」一个字一个字从虚到清，「电影」是红色 | 「强调词」换成标题里的另一个词；「刊头」「刊期」清空，顶上那一行应该消失 |
| 渐变扫光大字（gradient-word-sweep，3.5 秒） | 黑底上「火力全开」被彩色光从左扫到右，带几道闪电 | 取消勾选「闪电」；「起始色」「结束色」换两个颜色 |
| 套印错位标题（riso-print-hits，4 秒） | 「做出来，/ 要够响。」砸下来裂成粉、蓝两层，抖两下对准，最后盖一个章 | 「圆章文字」清空，应该不盖章；三条「信息」清空一条，剩下两条重新排开 |
| 首词放大成句（lead-word-zoom-assemble，3 秒） | 「这就是」先放大占满屏，再缩回去和「我们的新片」拼成一句 | 「首词」换成四五个字，看会不会出框 |
| 打字机改口（typewriter-moves，4 秒） | 先打出「它不只是幻灯片」，删掉「幻灯片」，改打「你的摄制组」，最后给「摄制组」铺一层底色 | 三段文字都改长一点，片段也要跟着拉长，不然没打完就结束了 |
| 极光翻底转折（aurora-bloom-bg-flip，5.5 秒） | 浅底上「以前，一支片要做几周」，紫光升起后整个底色压黑，换成「现在，一句话就够」 | 「光色」换一个颜色 |
| 花括号拉幕（brace-expand，4 秒） | 一对蓝色花括号弹开，中间露出「新片上线」 | 「标题」改成七八个字，括号应该跟着撑开，仍然贴着字的两边 |
| 字符坠落（type-entrance-moves，5 秒） | 「落地有声」四个字一个个砸下来，弹两下，歪着站住，最后一起摆正 | 「大字」改成英文单词，再改成两个字 |
| 空心字点亮（outline-word-fill，3 秒） | 空心的「更快」缩小落到圆圈中间，一下点亮成实心；两边是「以前 一周」「现在 四小时」 | 左右四个读数清空一侧；「大字」改成四个字，圆圈应该跟着变大 |
| 左右词合拢（text-column-converge，4.5 秒） | 左边「全新」不动，右边「字幕」「调色」「配乐」轮流换，换到「工作流」时两边合拢成一句 | 「轮换的词」加到五个，片段也要拉长到 5.5 秒以上 |

## 我自己觉得可能有问题的地方

- 左右词合拢这张，字本身很小（原卡就是小字），放在 1080p 上可能不够醒目，可以把「字号」拉大看看。
- 渐变扫光这张，原卡的大字和标语一样大，是一句话里的一个词被扫亮；现在改成了上面大字、下面小标语两层。
- 套印错位和打字机改口这两张没有原作者的预览视频可对照，是照代码做的，节奏如果觉得怪，告诉我。
- 中文句号在大字号下是个空心圈，这是字体本身的样子，第一批里也有。

觉得哪里不好看、哪个字段不好调，直接说感觉就行。
