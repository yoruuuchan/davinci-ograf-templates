# 第一批 5 张模板 · 达芬奇试用清单

这 5 张是用批量流水线做的（marker 那张是手写的），所以先看两件事：新做法在达芬奇里能不能正常跑；每张卡好不好用、好不好看。

## 准备

- 5 个文件夹都在 5090 的 `D:\ograf-test\batch1\` 下，每个文件夹里的 `fonts` 是模板自带的字体，要和 json 放在一起。
- 在测试工程 `OGrafTest_261109` 里新建一条时间线（1920×1080、30 帧）。
- 把每个文件夹里的 `<名字>.ograf.json` 导进媒体池，拖上时间线。

## 每张都看的

1. 拖上去能不能显示。空白或者报错的话，截图记下是哪一张。
2. 默认长度是不是清单里写的秒数，结尾有没有上飘淡出。
3. 检查器里改一两个字、改一个颜色，画面跟不跟着变。
4. 在片段中间来回拖播放头，画面不乱跳。

## 逐张看的

### 1. 纸面压印标题（paper-title-card，4 秒）

- 「你来导演，/ 让 AI 掌镜。」一个字一个字压出来，「掌镜」是褐色，下面一行「12 今日渲染镜头」，数字会滚动。
- 「标题」里按回车能不能换行。换不了的话，在要换行的地方输入 `\n` 试试。
- 把「纸面颜色」调成深色，中间那团柔光应该跟着变暗。

### 2. 列表逐项入场（list-reveal，4 秒）

- 左边六项依次弹出，第一项是白色高亮条，第四项挂一个「3」的徽章；右边标题等列表铺到一半才升起，副句最后出现。
- 「列表」一行一项。删到两项、加到八项各试一次，看排得好不好。
- 「当前项」填 0 是不高亮，「徽章项」填 0 是不显示徽章。

### 3. 字里有画（text-as-mask，5.5 秒）

- 大字「出片」是镂空的，字里透出一块深色数据面板，结尾画面顺着笔画冲满全屏。
- 「字里的画面」填一张你自己的图：在文件夹里选中图片，按 Ctrl+Shift+C 复制路径，粘贴进去。字里应该换成你的图，结尾冲满全屏的也是这张图。
- 把「结尾冲进画面」取消勾选，应该一直停在字里有画的状态。
- 「大字」换成三四个字，看会不会自动缩小、不出框。

### 4. 标题降为栏目标签（title-demote-to-label，4 秒）

- 大标题「分镜。」升起站稳，然后飞到左上角缩成小标签，下面长出导语和三张文字卡片。
- 把「卡片 3 标题」和「卡片 3 正文」都清空，应该只剩两张卡并重新居中。
- 「章节号」清空，眉题「第 01 节」和标签前的「01 /」都应该消失。

### 5. 手绘圈注（draw-svg-trace，4 秒）

这张是叠加层，没有背景，要放在一段视频的上面一轨。

- 一支笔沿着方框跑一圈把重点圈出来，上方出现「看这里」，下面画一道红色马克笔线。
- 下面一轨的视频要能透出来。如果看到的是黑底或白底，记下来：这说明达芬奇里的透明有问题，后面所有叠加类的卡都受影响。
- 拖「横向位置」「纵向位置」「框宽」「框高」，把框挪到你想圈的地方，看好不好调。

## 顺带补测 marker 那张

上次没测到的两项，在 `marker-underline-title-v0.2` 上试：

- 勾上「透明背景」，纸面消失，下面一轨的视频透出来。
- 交付页导出 QuickTime、Apple ProRes 4444、勾上「导出 Alpha」，把导出的文件拖回时间线，放在一段视频上面，字浮在视频上、没有黑底。
