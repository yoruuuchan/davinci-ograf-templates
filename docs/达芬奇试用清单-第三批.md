## 开始前

- 测试工程 `OGrafTest_261109`；媒体池 `主媒体夹 / 04第三批（16张） / <序号名称>`，双击里面的时间线。
- 每张先播一遍再动字段；改了画面不跟，先挪一下播放头再看。

## 每张都先看这四样

1. 播一遍：动作、默认画面跟名字对不对得上；空白或报错就截图。
2. 片段默认长度是不是表里的秒数，结尾有没有上飘淡出。
3. 检查器里改一处文字、一处颜色，画面跟不跟着变。
4. 中间来回拖播放头，画面不乱跳。

### 16 滚带定针读数（`gauge-readout-moves-tape`）· 5.0 秒

  - 要看：留空就不显示
