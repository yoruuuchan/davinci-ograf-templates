3. 检查器里改一处文字、一处颜色，画面跟不跟着变。
4. 中间来回拖播放头，画面不乱跳。

### 01 负片打击帧急推（`impact-feedback-anime-impact`）· 4.0 秒 · 叠加层

默认画面：一记重拳打在一张画面上：镜头先缓慢推进、锁定中央偏上的目标框，短促回拉后六帧急推撞停；三帧整幅负片 + 手绘放射集中线 + 红青色散，随后恢复干净特写并震屏衰减

试这些：

- 【画面】「被打的图」填一张图（选中图按 Ctrl+Shift+C 复制路径，粘贴进来）
  - 要看：留空则效果打在中间的中性占位画面上，下面的画面从四周透出来，但不会被反色
- 【手感】「目标横%」拉到最小、再拉到最大（默认 50，上限 100）
  - 要看：目标框中心在画面宽度里的百分比，0–100，相对铺满后的画面
- 【画面】「集中线颜色」换成 #c0392b，再换成浅色 #f4efe6
  - 要看：冲击帧放射集中线的亮色
- 【画面】叠在 V1 素材上：没画东西的地方要透出下面的视频，黑底/白底就是不通过。
- 【好看】节奏顺不顺；配色在你自己的片子里好不好看。
